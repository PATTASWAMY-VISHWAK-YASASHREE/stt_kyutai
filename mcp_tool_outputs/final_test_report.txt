## TROUBLESHOOTING GUIDE

### Issue: Audio not transcribing
Check:
1. Server logs for errors
2. Audio file format supported
3. Audio contains speech
4. Audio duration > 0.5 seconds

### Issue: WebSocket disconnects
Check:
1. WS_TIMEOUT setting (default 300s)
2. Network stability
3. Browser console errors
4. Server logs for connection errors

### Issue: Slow transcription
Check:
1. Audio file size (< 10MB recommended)
2. Processing mode (FAST vs QUALITY)
3. System resources (CPU/RAM)
4. Model on CPU vs GPU

### Issue: Empty transcription
Check:
1. VAD not filtering all audio
2. Audio volume sufficient
3. Speech clarity
4. Language supported (en/fr)
