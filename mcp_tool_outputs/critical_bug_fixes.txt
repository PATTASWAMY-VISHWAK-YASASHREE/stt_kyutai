## BUG #1: Unsupported Parameter in Feature Extractor

### Error Message:
```
TypeError: KyutaiSpeechToTextFeatureExtractor.__call__() got an unexpected 
keyword argument 'return_attention_mask'
```

### Root Cause:
The `KyutaiSpeechToTextFeatureExtractor` does not support the 
`return_attention_mask` parameter that was being passed to it.

### Location:
`encoding.py`, line 390-397

### Previous Code:
```python
if hasattr(self.processor, 'model_input_names'):
    if 'attention_mask' in self.processor.model_input_names:
        processor_kwargs["return_attention_mask"] = self.config.return_attention_mask

processor_kwargs.update(kwargs)

# Call processor
return self.processor(audio=audio, **processor_kwargs)
```

### Fix Applied:
```python
# Remove return_attention_mask - not supported by KyutaiSpeechToTextFeatureExtractor
# Only pass parameters that are actually supported
if 'return_attention_mask' in processor_kwargs:
    del processor_kwargs['return_attention_mask']

processor_kwargs.update(kwargs)

# Call processor
return self.processor(audio=audio, **processor_kwargs)
```

### Impact:
- **CRITICAL**: Blocked all transcription attempts
- Model could load but couldn't process any audio
- Warmup inference failed

### Status: ✅ FIXED

## BUG #2: Audio Decoder Error Message Formatting

### Error Message:
```
soundfile decoding failed: 'function' object has no attribute 'replace'
```

### Root Cause:
Two issues in the soundfile decoder:

1. **handle.format** was a function, not a string
2. Exception objects weren't converted to strings before formatting

### Location:
`audio_processor.py`, multiple locations

### Fix #1: Safe Codec Extraction (lines 362-371)

**Previous Code:**
```python
metadata = AudioMetadata(
    codec=handle.format,
    bit_depth=bit_depth,
    file_size=len(audio_bytes),
)
```

**Fixed Code:**
```python
# Get codec/format safely
codec = None
if hasattr(handle, 'format'):
    # handle.format might be a property or attribute
    fmt = handle.format
    codec = str(fmt) if fmt is not None else None

metadata = AudioMetadata(
    codec=codec,
    bit_depth=bit_depth,
    file_size=len(audio_bytes),
)
```

### Fix #2: Proper Exception String Conversion (lines 897-901)

**Previous Code:**
```python
except AudioDecodingError as e:
    errors.append(f"{decoder.name}: {e}")
    logger.debug(f"Decoder {decoder.name} failed: {e}")
```

**Fixed Code:**
```python
except AudioDecodingError as e:
    # Convert exception to string properly
    error_str = str(e)
    errors.append(f"{decoder.name} decoding failed: {error_str}")
    logger.debug(f"Decoder {decoder.name} failed: {error_str}")
```

### Impact:
- **HIGH**: Audio decoding would fail with confusing error messages
- Secondary decoders couldn't be tried properly
- Error reporting was broken

### Status: ✅ FIXED

## ROOT CAUSE ANALYSIS

### Why These Bugs Occurred:

1. **Feature Extractor Bug:**
   - Code was written generically for multiple model types
   - Kyutai STT model has different parameter requirements
   - No model-specific parameter validation

2. **Audio Decoder Bug:**
   - soundfile library API differences across versions
   - `handle.format` property behaves differently
   - Exception objects not always stringifiable

### Prevention Strategies:

1. **Model-Specific Testing:**
   - Test each model type individually
   - Validate supported parameters
   - Check API documentation

2. **Defensive Error Handling:**
   - Always convert exceptions to strings explicitly
   - Use safe attribute access (hasattr + type conversion)
   - Never assume object types

3. **Integration Testing:**
   - Test full pipeline end-to-end
   - Include multiple audio formats
   - Verify error messages are readable

═══════════════════════════════════════════════════════════════

## LESSONS LEARNED

1. **Don't Assume API Compatibility:**
   - Just because a parameter exists doesn't mean all models support it
   - Always check model-specific documentation

2. **Error Messages Matter:**
   - "'function' object has no attribute 'replace'" was cryptic
   - Proper string conversion makes debugging easier

3. **Test Early, Test Often:**
   - These bugs only appeared at runtime
   - Unit tests for parameter validation would have caught this

4. **Defensive Programming:**
   - Use str() explicitly when converting to strings
   - Check types before operations
   - Handle edge cases gracefully
