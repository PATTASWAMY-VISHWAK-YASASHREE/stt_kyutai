## CURRENT ARCHITECTURE

### Server Stack
- FastAPI: Web framework with WebSocket support
- Uvicorn: ASGI server running on 0.0.0.0:8000
- TranscriptionService: Main service class
- ConnectionManager: WebSocket connection management

### Transcription Pipeline
1. **Audio Input:** Bytes from WebSocket or file upload
2. **Decoding:** EnhancedAudioProcessor with multi-backend support
   - Primary: SoundFile (fast, native formats)
   - Fallback 1: PyDub (ffmpeg-based, all formats)
   - Fallback 2: Librosa (scientific audio)
3. **Processing:** FastTranscriptionEngine
   - Mode: FAST (balanced speed/quality)
   - Cache: 1000 entries
4. **Model:** Kyutai STT-1B (auto-loaded on first transcription)
5. **Output:** TranscriptionResult with text and metrics

## TROUBLESHOOTING

### Server Won't Start
Check:
1. Port 8000 is available
2. Virtual environment activated
3. All dependencies installed
4. Python 3.8+ (current: 3.13.9)

### Audio Decoding Fails
Check:
1. Audio file is valid format
2. pydub installed (fallback)
3. ffmpeg available on system (for pydub)

### Transcription Returns Empty
Check:
1. Audio contains speech
2. Audio duration > 0.5 seconds
3. Volume is audible
4. VAD not filtering out all audio

### WebSocket Connection Fails
Check:
1. Server is running
2. Correct URL: ws://localhost:8000/ws
3. CORS settings (currently allows all origins)
4. Browser console for errors
